# AI Assistance

I used AI during the development of this project mainly as a development assistant and for code review.

## What I Used AI For

- Generating and reviewing some boilerplate code.
- Helping with React form validation and NestJS DTO validation.
- Reviewing the authentication flow and protected routes.
- Reviewing security practices such as password hashing and JWT authentication.
- Helping with Docker and project documentation.

## Prompts That Were Useful

Some useful prompts were:

- "Review this authentication implementation for security issues."
- "Check if this validation meets the task requirements."
- "Review this NestJS code and suggest improvements."

## Corrections and Rework

AI suggestions were reviewed before being used. Some generated code needed to be adapted to the existing project structure, dependencies, and implementation decisions.

I also verified authentication, validation, environment configuration, and Docker setup rather than relying on generated code without testing it.

AI was mainly used to speed up development and review, while the final implementation and technical decisions were made and verified by me.
